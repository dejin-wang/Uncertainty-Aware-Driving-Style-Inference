# Uncertainty-Aware Driving-Style Inference

Official implementation of the paper:

"Uncertainty-Aware Driving-Style Inference Using Interpretable Continuous Traits"

This repository implements a continuous latent driving-style inference framework with uncertainty quantification, evaluated on Highway env.

The experiments are conducted using the following simulation environments:

1. CARLA: 0.9.13

2. Highway-env: 1.10.1

The CARLA simulator (v0.9.13) is used for high-fidelity driving scenarios with realistic vehicle dynamics and perception interfaces. The Highway environment (v1.10.1) is used for controlled evaluation under lightweight traffic simulation with configurable traffic density and behavior.
